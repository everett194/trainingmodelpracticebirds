These are portfolio/educational models exploring reported wildlife-strike damage and airport-area bird-migration monitoring data. They are not an operational aviation-safety system, and no output here should be used to make real aviation safety decisions. For the main Eastern Shore dashboard, see Dashboard.

Synthetic educational demo

The original 8-input neural network, trained on entirely synthetic, hand-designed data - see synthetic_demo/README.md. Unrelated to real FAA/Trektellen data.

Model trained: {{ "yes" if synthetic_model_available else "no — run synthetic_demo/train.py first" }}

GA conditional-damage model (CatBoost)

Estimated probability of aircraft damage, conditional on a reported wildlife strike, for the confirmed business/private fixed-wing GA population. Trained on the FAA Wildlife Strike Database with CatBoost and calibrated. Pick a named scenario to see a live prediction. The dashboard's damage SHARES are an observed proportion (damaging reports / known-outcome reports); this model's output is a separate, trained prediction - see Methods for how the two relate.

Model trained: {{ "yes" if ga_damage_model_available else "no — run scripts/ga_train_models.py first" }}

Reported-strike damage model (legacy)

Estimated probability of aircraft damage, conditional on a reported wildlife strike. Trained on ALL aircraft types in the FAA Wildlife Strike Database (not GA-filtered), with a more permissive feature policy than the GA damage model. Preserved as a working PyTorch architecture demonstration — see LEGACY_SYSTEMS.md for why the GA damage model is primary.

Model trained: {{ "yes" if damage_model_available else "no — run scripts/train_models.py first" }}

Airport wildlife activity explorer (legacy)

A relative activity_index for an airport and time period, computed from a transparent hand-picked formula over nearby Trektellen bird-migration monitoring observations (not a trained model). Preserved for its formula-based approach — see LEGACY_SYSTEMS.md and the hazard index for the current primary hazard/activity output.
