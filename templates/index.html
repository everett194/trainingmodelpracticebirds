BirdStrikeGeo is a portfolio/educational project exploring reported wildlife-strike damage and airport-area bird-migration monitoring data. It is not an operational aviation-safety system, and no output here should be used to make real aviation safety decisions.

1. Synthetic educational demo

The original 8-input neural network, trained on entirely synthetic, hand-designed data - see synthetic_demo/README.md. Unrelated to real FAA/Trektellen data.

Model trained: {{ "yes" if synthetic_model_available else "no — run synthetic_demo/train.py first" }}

2. Reported-strike damage model

Estimated probability of aircraft damage, conditional on a reported wildlife strike. Trained on FAA Wildlife Strike Database records (real data) or synthetic sample fixtures. Never a prediction of whether a strike will occur.

Model trained: {{ "yes" if damage_model_available else "no — run scripts/train_models.py first" }}

3. Airport wildlife activity explorer

A relative activity_index for an airport and time period, built from nearby Trektellen bird-migration monitoring observations. Not a strike probability.

Data available: {{ "yes" if activity_data_available else "no — run scripts/generate_sample_data.py first" }}
