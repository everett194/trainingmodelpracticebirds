BirdStrikeGeo is a portfolio/educational project exploring reported wildlife-strike damage and airport-area bird-migration monitoring data. It is not an operational aviation-safety system, and no output here should be used to make real aviation safety decisions.

1. Synthetic educational demo

The original 8-input neural network, trained on entirely synthetic, hand-designed data - see synthetic_demo/README.md. Unrelated to real FAA/Trektellen data.

Model trained: {{ "yes" if synthetic_model_available else "no — run synthetic_demo/train.py first" }}

4. GA conditional-damage model (CatBoost) — ★ primary

The current, authoritative damage model: estimated probability of aircraft damage, conditional on a reported wildlife strike, for the confirmed business/private fixed-wing GA population. Trained on the FAA Wildlife Strike Database with CatBoost and calibrated. Pick a named scenario to see a live prediction.

Model trained: {{ "yes" if ga_damage_model_available else "no — run scripts/ga_train_models.py first" }}

5. Bird-hazard index (Eastern Shore/FBBO) — ★ primary

The current, authoritative secondary output: exploratory analysis joining nationwide per-species strike-severity risk against a 2025 Trektellen banding station's local bird activity on Maryland's Eastern Shore. Not a calibrated strike probability - see the report for caveats.

Report available: {{ "yes" if hazard_report_available else "no — run scripts/build_eastern_shore_risk_report.py first" }}

2. Reported-strike damage model (legacy)

Estimated probability of aircraft damage, conditional on a reported wildlife strike. Trained on ALL aircraft types in the FAA Wildlife Strike Database (not GA-filtered), with a more permissive feature policy than mode 4. Preserved as a working PyTorch architecture demonstration — see LEGACY_SYSTEMS.md for why mode 4 is now the primary damage model.

Model trained: {{ "yes" if damage_model_available else "no — run scripts/train_models.py first" }}

3. Airport wildlife activity explorer (legacy)

A relative activity_index for an airport and time period, computed from a transparent hand-picked formula over nearby Trektellen bird-migration monitoring observations (not a trained model). Preserved for its formula-based approach — see LEGACY_SYSTEMS.md for why mode 5 is now the primary hazard/activity output.

Data available: {{ "yes" if activity_data_available else "no — run scripts/generate_sample_data.py first" }}
